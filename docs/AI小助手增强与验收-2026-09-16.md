# AI 小助手增强与验收

本轮将助手从页面跳转入口扩展为“查询业务数据 → 展示依据 → 教学问答 → 生成草稿 → 核对发布”的连续工作流。

## 常驻聊天与页面问候

保留上述能力，并恢复按页面推荐常用操作的开场方式。高级查询、自然语言理解和模型问答继续支持自由对话。

| 页面 | 自动问候中的常用功能 |
| --- | --- |
| 班级学情 | 班级画像建议、查看班级学情、带入教学设计、生成补弱练习 |
| 个人学情 | 当前学生的画像建议、查看该生学情、带入教学设计、知识点解释 |
| 学情知识图谱 | 图谱读法、概念解释、素养找题 |
| 资源题库 | 数学抽象题、逻辑推理题、真题、同步练习、标签解释 |
| 资源知识图谱、教案、课件 | 分别提供图谱解释、资源选用、课堂导入等入口 |
| 教学设计 | 带入班级学情、备课流程、分层提问 |
| 作业组卷与下发 | 补弱/复习草稿、策略选择、作业查询、发布流程 |
| 作业批改与课程资源 | 反馈措辞、错因辨析、材料组织、课堂检查问题 |

- 默认右下角常驻聊天，支持切换右侧栏。位置偏好保存在本机；没有把聊天内容和学生数据写入位置配置。
- 桌面宽屏侧栏为业务页面预留空间。窄屏可切回浮窗，聊天输入始终可用。
- 浮窗模式下，页面或嵌套业务容器滚动时，聊天内容降低透明度并轻微模糊，停止滚动约450毫秒后恢复。聊天内部滚动和正在输入不触发虚化；侧栏独立占位时保持稳定显示。
- “让出页面”可持续虚化聊天并允许点击下方内容，标题栏保留“恢复聊天显示”按钮；不会清空或关闭聊天。
- 切换页面、学情页签、班级、学生或资源页签，追加一条对应的问候；返回已访问页面也会重新问候。仅调整日期、来源等筛选时不追加问候。
- 切页、位置切换保留消息、当前任务、未发送输入和正在生成的回答。迟到回答保留发起页面标记，旧页面建议不会覆盖新问候。
- 问候不进入模型对话历史，也不使已有发布确认失效。页面快捷操作使用该页的班级/学生；当前页筛选变化后使用最新筛选，历史页面的快捷入口保留原对象。
- 修复个人建议未传名单时可能扩大为全班的问题：个人建议默认只为对应学生生成练习，显式子名单继续保留。
- 画像建议接口仍使用原有画像口径，在建议区域标注；明细问答和定向查询继续使用日期、来源、知识点筛选。

| 消歧 | 查看彭圆上月学情；查看 peng yuan 的学情 | 错别字、拼音、部分姓名和重名显示候选，选择后继续原查询，不静默猜人 |
| 范围筛选 | 只看近两周；只看作业记录；只看二次根式 | 日期、来源、知识点真正参与明细统计；跳转个人学情保留条件 |
| 依据解释 | 依据这些证据怎么辅导她？ | 模型收到对应学生、范围、题号、作答结果；区分观察事实与待验证错因 |
| 学生比较 | 比较彭媛和侯秀2026年8月学情 | 使用相同日期、来源和知识点比较，支持“比较她和侯秀” |
| 条件名单 | 1班2026年8月正确率低于60%的学生 | 重新统计明细后筛选；少于3条证据不纳入确定性判断 |
| 变化查询 | 1班近两周正确率下降的学生 | 与前一个等长时段比较，两段都需要至少3条记录 |
| 找题 | 给彭媛找5道二次根式题，不要选择题，排除做过的 | 支持题数、知识点、素养、难度、题型、来源和排除条件；不足时不放宽 |
| 定向草稿 | 给这两个人生成5道二次根式练习，先别发 | 实际调用题库，保存精确名单、配置、逐生试卷；在现有组卷页预览 |
| 换题 | 第2题换掉 | 保留名单、原知识点和限制，整批校验通过后替换；候选不足保持原稿 |
| 教学内容 | 为彭媛写上月二次根式教学片段 | 根据学情生成草稿，模型深化例题、课堂追问和分层方案；可编辑、复制、下载或带入教案表单 |
| 沟通稿 | 改写成家长沟通稿 | 引用当前学生和查询范围；生成文本草稿，不发送消息 |
| 作业查询 | 查看作业提交情况；帮我写催交文案 | 读取作业记录；真实提交字段缺失时明确说明，模拟报告不冒充真实提交 |
| 多步任务 | 先看彭媛上月学情，再给她生成3道二次根式练习，并写教学片段 | 最多串联3步，共用解析后的对象和条件；消歧或错误会停止后续步骤 |
| 发布 | 发布这份草稿，截止明晚8点 | 展示具体学生、可展开试卷和截止时间；点击一次确认后执行，返回演示系统回执 |
| 连续对话 | 换侯秀；只看近两周；给这些学生生成练习 | 任务独立于当前页面，跨页保留；新对话、账号切换清理旧任务和迟到回答 |
| 教师问答 | 学生把根号下a的平方写成a，怎么用反例讲清楚？ | 可解释数学、逐步解题、核查结论、设计课堂提问，不再限制为200字页面介绍 |

## 数据口径与执行边界

- 当前项目使用已有 mock/teacher 数据和会话内作业存储。验收在演示环境完成，不能据此宣称已连接学校真实数据库或学生端。
- 演示明细集中在2026年8月。默认查询跟随已注册的页面筛选，否则使用本月。无记录时显示“当前范围无作答明细”和最近可用记录日期。
- 观察正确率 = 范围内答对明细数 / 范围内有效明细数。明细是抽样记录，不等于完整历史掌握度；个人学情页也显示这一说明。
- 定向草稿与现有作业预览共用存储。演示页面刷新或服务重启可能使草稿失效，失效后明确提示。对话会话保留两小时，并有数量上限。
- “怎么布置”只解释；“先别发”不会发布。新指令和修改草稿使旧确认失效。确认校验草稿版本，重复确认返回同一发布结果。
- 没有真实提交记录时不生成真实未交名单，不替老师发送催交或家长消息。

## 模型接入

通过同源 POST /api/assistant/model 调用服务器端 GLM。模型负责教学回答和只读语义补全，业务统计、名单和执行结果由数据工具产生。

- server/assistant-model.cjs：服务器配置、提示词、超时、请求体上限和并发限制。
- mock/assistantModel.ts：开发 mock 服务路由。
- scripts/preview-demo.js：本地演示预览提供同样的模型路由。
- 环境变量：ZHIPU_API_KEY、可选的 ZHIPU_MODEL。也支持根目录 .assistant.local.json，格式为 {"apiKey":"你的密钥","model":"glm-4.6"}；已加入忽略规则。
- 沿用本机现有模型配置并移入助手的服务器本地配置，浏览器构建不包含助手密钥。原有 aiGuide 用户改动保留。
- 纯静态托管没有模型路由时，数据查询、找题和草稿仍可用，模型回答显示离线提示。
- 本地启动：先执行 npm run build:demo，再执行 npm run preview:demo。

生产接入需要把数据适配层替换为鉴权后的班级/学生/作业接口，将会话、草稿和发布幂等信息存入后端持久化存储。真实提交状态取决于后端是否提供提交记录。

## 验收方式

- node tests/assistant-regression.cjs：业务规则、统计、消歧、名单约束、换题、确认失效、幂等、多步任务和建议卡。
- node tests/assistant-browser.cjs：实际操作、跨页、组卷预览、编辑教学草稿、停止/重置和真实模型问答。
- node tests/assistant-presentation-regression.cjs：页面场景识别、旧上下文隔离、当前筛选、个人建议名单与班级建议边界。
- node tests/assistant-presentation-browser.cjs：自动问候、浮窗/侧栏、输入保留、学生切换、迟到建议、历史回退、滚动虚化、点击穿透和移动端。
- npm run test:performance、node tests/boundary-regression.cjs：缓存、请求隔离、鉴权探针和竞态回归。
- node tests/performance-browser.cjs、node tests/boundary-browser.cjs：原有页面流转和异常恢复。
- 浏览器脚本使用已有 Playwright 工具，可设置 PLAYWRIGHT_MODULE 指向 .temp/perf-tools/node_modules/playwright-core。

## 验收结果

- 演示构建成功，差异空白检查通过，构建包中未发现本机助手密钥。
- 助手业务回归：49个用例通过。
- 页面问候与对象隔离逻辑：11个用例通过；常驻聊天交互浏览器验收：14个场景通过，包括侧栏避让、浮窗穿透、筛选不重复问候和切页确认连续性。
- 助手浏览器验收：16个场景通过，包含实际 GLM 问答、精确跳页、草稿流转、否定发布、迟到回答隔离、移动端位置切换；无页面异常。
- 原有边界浏览器回归：14个场景通过，无页面异常。
- 页面性能回归：14次流转通过，48次接口请求，无未匹配接口或页面异常；常驻聊天版本最终本地测量约32–331毫秒。该数值不代表生产网络性能。
- 数据查询、比较和草稿操作在常驻聊天版本本地浏览器测量约57–538毫秒。真实模型问答样本约16.9秒；服务超时可停止或重试，已取得的数据结果仍保留，菜单和页面可操作。
- 原有缓存/请求/鉴权回归通过。旧脚本已适配当前代码的权威鉴权探针，以及此次明确要求的跨页会话保留。
- 使用 TypeScript 5.7.3 额外执行了全量检查（跳过第三方声明检查）。项目仍有704项类型诊断，不能声称全库类型检查通过；新增助手引擎、查询范围、选题模块和助手面板没有类型诊断。此次修改文件中剩余一项 TeacherProfile 导入组件属性诊断位于原有代码行，属于项目类型基线问题。

浏览器详细运行记录和截图保存在 .temp/assistant、.temp/assistant-presentation、.temp/boundary 和 .temp/performance 下。截图人工检查了面板、公式展示和教学草稿带入表单的效果。
