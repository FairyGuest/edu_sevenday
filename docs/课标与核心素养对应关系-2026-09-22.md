# 课标与核心素养对应关系（2026-09-22）

定位：对用户提供资料的初步梳理，重点是“课程内容如何对应学科素养”，不是逐页校勘、正式评价量规或全学科实施承诺。
本轮读取了各学科核心素养定义，并重点核对初中数学的内容要求、学业要求、教学提示和评价建议。
需求状态：五个核心点是侧重点，不是全部范围；二.3 当前不实施，二.4 暂缓保留。完整意见追踪已同步更新到需求文档 V0.2。

## 1. 资料情况

- 共 20 份 Markdown：义教 9 学科 + 课程方案，高中 9 学科 + 课程方案。
- 文件自标版本：义教“2022年版2025年修订”，高中“2017年版2025年修订”；本轮未联网或对照原 PDF 核验版本。
- 已有课标原文可用于提取学科素养、课程内容、学业要求与学业质量，不再将“课标未提供”作为阻塞。
- 教材的第几章、第几节不是由课标统一编号，需要具体教材目录另行对应。
- 原文包含长 HTML 表格、跨行文字和公式转写异常，引用的 images 文件夹当前缺失。可先做概括，关键题意、公式及等级锚例接入前要校对。

## 2. 核心结论

课标不是“知识点标签加几个素养词”。对应关系应拆成两条不同的链：

1. 教学对应：教材章/节 → 课标内容与学业要求 → 相关素养表现 → 教学目标与任务。
2. 评价对应：学生完成任务的实际证据 → 量规与表现描述 → 本次任务的素养表现判断。

第一条能说明“这里适合培养/考查什么”，不能单独证明“学生已经具备什么”。
一个章节对应多项素养，一项素养也需要跨章节、跨任务的证据积累；不是固定一对一关系，更不是一张预设权重表。

需要同时保留三个层次：
- 课标原文明确的关系：记录原文出处。
- 根据教学内容提出的候选关系：标为教学推导，待教研审查。
- 学生表现结论：必须有实际证据与经过审核的量规，不能由课程标签直接生成。

产品含义：
- 不再给所有学科统一套“逻辑、表达、创新、合作”四个分数。
- 配置键至少包含学科、学段和课标版本，必要时进一步限定年级。
- “能力画像”展示本学科任务中可观察的表现；“素养画像”按该学科课标组织，两者共享证据，不重复制造两套分数。
- 英语明确包含学习能力，不意味着所有学科都把“学习能力”作为同名核心素养轴。
- 不能用课程列出的价值目标推断某位学生的私人信念或稳定人格；只能解释有授权证据支撑的任务表现。

## 4. 当前数学演示应如何对应

### 4.1 初中数学的“三会”和九项主要表现

课标的三个方面 [M1]：

| 三个方面 | 原文关联的主要表现（按初中用语归纳） |
| --- | --- |
| 会用数学的眼光观察现实世界 | 抽象能力、几何直观、空间观念、创新意识 |
| 会用数学的思维思考现实世界 | 运算能力、推理能力 |
| 会用数学的语言表达现实世界 | 数据观念、模型观念、应用意识 |

课标列出的初中九项主要表现 [M2]：
抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识。

表中的分组用于理解原文，不是互斥分类，也不是三个维度相加计分的算法。
小学另有数感、量感、符号意识、推理意识、数据意识、模型意识等阶段表述，不能直接照搬为初中九项画像。
高中六项素养不能拿来替换当前八年级数学框架。

### 4.2 课程内容与素养表现的对应草案

“原文直接”指文件在领域/主题或学业要求中明确联系；具体题目和证据示例是产品建议，仍需审核。
下表不是课标给出的逐节标签全集，也不表示每道同主题题目都能测到全部所列素养。

| 内容范围 | 可关联的主要表现 | 原文依据 | 可观察证据建议 |
| --- | --- | --- | --- |
| 数与式、二次根式等 | 运算能力；有概括、解释任务时关联抽象能力和推理能力 | 数与代数领域概述 [M4]、数与式教学提示 [M7]；具体根式任务映射为教学推导 | 运算步骤、算理解释、检验结果；只有最终答案时不推断完整推理能力 |
| 方程与不等式 | 模型观念，结合任务观察抽象、运算和推理 | 学业要求明确“建立模型观念” [M5] | 从文字条件列关系式、求解、检验结果是否符合实际 |
| 函数、一次函数 | 抽象能力、模型观念、几何直观、应用意识；解释论证时可关联推理 | 函数概念学业要求 [M6]、教学提示 [M7] | 识别变量、图式互译、解释斜率/截距的情境含义、讨论适用范围 |
| 图形的性质、勾股定理等 | 几何直观、推理能力；依具体任务关联抽象能力、应用意识 | 图形性质学业要求 [M8]；勾股任务细分为教学推导 | 图形关系识别、推理依据、说明何时能用定理；不能只看算出边长 |
| 图形的变化、图形与坐标 | 几何直观、空间观念；坐标表达与论证任务可关联运算、推理、应用 | 图形学业要求与教学提示 [M8] | 图形变换前后关系、坐标表达、解释不变量及实际意义 |
| 统计与概率 | 数据观念、模型观念；具体论证时可关联推理能力 | 领域概述和学业要求 [M9] | 选择抽样方法、解释统计量、判断代表性、说明概率模型条件 |
| 综合与实践 | 按任务关联模型、数据、应用和创新等表现 | 学业质量关于真实情境、经验积累的描述 [M10] | 问题提出、方案比较、数据/作品、修正记录，不以提交作品次数计分 |

重要范围限制：所提供初中数学文件对二次根式四则运算注明“根号下仅限于数” [M12]。
因此旧 Mock 中含参数根式变形、跨学段题目应对照具体条文审核，不能仅挂上“二次根式”就认为符合课标。
本轮不直接修改题库；数据清单中的候选诊断示例已改为数值型问题，避免默认采用未经复核的含参迁移题。

### 4.3 一个可用于演示的对应实例

内容：一次函数的图象与实际意义。

- 课标要求：能根据实际问题确定表达式，结合图象与表达式分析和解决问题 [M6]。
- 教学任务建议：给出校园用水量随时间变化的数据，让学生选择变量、建立关系、画图并解释参数。
- 抽象能力证据：能区分需要的变量和无关信息，说明变量间关系。
- 几何直观证据：能把表达式、数据与图象对应，借图解释变化。
- 模型观念证据：能说明模型假设、适用区间，并检验与现实是否一致。
- 运算能力证据：求解过程与结果合理。
- 推理/应用证据：解释为什么采用该模型以及结论在情境中意味着什么。

若学生只是按给定公式代入算对，只支持该任务内的运算表现，不能同时自动生成“模型观念优秀”等结论。
以上任务是产品建议，不是课标原题，不标为官方测评样例。

## 5. 如何从对应关系进入画像

### 5.1 拆开“应关注”与“已观察到”

教师选某章/节后：
1. 从教材目录映射到课标内容条目。
2. 显示本范围相关的素养表现及出处，说明为什么关注这些项。
3. 从学生任务、步骤、作品和观察记录中筛出当前范围证据。
4. 分别显示“有表现证据”“证据不足”“尚未采集”“待复核”。
5. 只有量规适用且证据充分时形成对应任务的评价；跨任务阶段性画像另外聚合。

选一次函数后没有协作任务记录，不应生成合作分；没有模型建立过程，不应生成建模水平。
没有被当前任务涉及的素养应标“本范围未覆盖”，不能与“涉及但没有采集到证据”混为一类。

### 5.2 来源和专业解释

| 来源 | 数学场景中的可用内容 | 避免的做法 |
| --- | --- | --- |
| 作业、考试、自主练习 | 步骤、方法选择、条件解释、订正与迁移 | 正确率直接等于所有素养 |
| 课堂互动 | 对数学结论的解释、质疑、反例和依据 | 发言次数直接等于推理能力 |
| 人机交互 | 学生是否核对 AI 结果、给出理由并修正 | 对话轮数直接等于学习能力 |
| 小组协作 | 个人提出的理由、回应同伴后的修改、可追溯贡献 | 全组成绩均摊成每个人素养 |

课标评价建议本身列出书面/口头测验、活动报告、课堂观察、访谈、作业、成长记录等 [M11]。
因此原意见一.4 仍需做数据和解释层建设；不以暂时不做课堂视频采集为由忽略该需求。

学习经验、习惯和自我反思也在初中数学学业质量描述中出现 [M10]。
它们应以过程证据补充画像和教学设计，不能替代学科核心素养，更不能通过成绩推断动机。

## 6. 最小映射数据结构

先建立“对应表”，不要先为每项素养编造一个分数：

| 实体 | 最低字段 |
| --- | --- |
| 课标文档 | document_id、学科、学段、原文件自标版本、来源路径、内容哈希、校对状态 |
| 内容条目 | clause_id、所属领域/主题、原文、章节路径、行/页定位、内容或学业要求类型 |
| 素养条目 | competency_id、原文名称、学段、定义、所属框架与原文定位 |
| 教材映射 | textbook_id/version、chapter_id、section_id、clause_ids、审核状态 |
| 对应关系 | clause_id、competency_id、mapping_basis、解释、source_refs、review_status |
| 可观察指标 | indicator_id、任务条件、所需证据、允许/禁止的解释、rubric_id/version |
| 学生证据 | task/attempt/evidence_id、学生/班级、时间、课程范围、过程片段与观察 |
| 评价结论 | 使用的证据和量规版本、结论适用范围、复核状态、缺失与冲突说明 |

mapping_basis 分为 direct_text（原文明示）、pedagogical_inference（教学推导）。
是否经专家确认单独存为 review_status，不能把“模型认为有关”记成“课标直接规定”。
clause_id 为系统内部定位 ID，不得冒充课标官方条文编号。
不在这一层预设“某章对应某素养 30%”之类权重。权重、等级、样本门槛属于另需论证的评价规则。

## 7. 对本轮需求的影响

- 当前可做：按章/节展示相关课标要求与素养；画像按学科/学段配置；教学目标与内容建立出处关系；补任务和错因证据。
- 一.3 保留：课标提供目标与表现依据，但专家量规、锚例、试评与实际数据支撑仍必需。
- 二.1 保留：初中数学课标明确“基于主题、单元整体设计教学目标，围绕单元目标细化具体课时” [M13]。
- 二.2 保留：多维学情、真实问题和情境—任务—评估可以先落在教案字段、内容与 Mock，不依赖对话分步界面。
- 二.3 当前不实施：不开发海淀定制，也不把海淀模板列为本期前置。
- 二.4 暂缓：分步对话、场景选择框架、布鲁姆分类辅助保留需求记录，不纳入当前验收。
- 三、四部分保留：错因干预不刷题；教研场景工具；非表面行为评价；可定制合作要求；竞品调研和评估规则结构化。

后续建议先用“二次根式、一次函数、勾股定理、统计与概率”制作一份少量高质量的章/节—课标条文—素养表现对应表。
这是对当前数学 Mock 的优先顺序，不代表删除其他学科需求，也不意味着直接给每章全部九项素养打分。
