# 教师端画像与校本教研验收标准

## 1. 验收目标

本验收标准用于约束后续实现：在补齐四维画像、证据解释、知识图谱筛选和校本教研一级菜单后，现有系统不能崩溃，已有主链路不能回退。

本次验收重点：

- 不重构首页。
- 不破坏现有左侧菜单和路由。
- “校本教研”作为左侧一级菜单新增。
- 学情分析页保持原有整体 Tab，只做画像和解释增强。
- 班级画像与个人画像同构。
- 新增四维画像后页面可加载、可切换、可解释。
- 新旧 mock 数据缺字段时页面有兜底，不白屏。

## 2. 页面与路由验收

### 2.1 左侧菜单

验收项：

- 左侧菜单新增“校本教研”。
- “校本教研”与“学情分析、教学设计、作业组卷、作业下发、作业批改”等并列。
- 点击“校本教研”进入独立页面，例如 `/school-research` 或产品确认后的等价路由。
- 新增菜单不影响已有菜单选中态。
- 刷新校本教研页面后仍能正常显示。

不通过情况：

- 把校本教研做进学情分析内部 Tab。
- 点击校本教研导致 404。
- 新增菜单后已有菜单无法跳转或选中态错乱。

### 2.2 首页

验收项：

- 首页保持当前产品结构，不改成六环节 AI 工作台。
- 在线作业、互动记录、常用智能体、消息提醒等现有模块正常展示。
- 首页没有因新增校本教研、画像字段而报错白屏。

不通过情况：

- 首页结构被大幅替换。
- 首页依赖新 mock 字段，旧数据下白屏。

### 2.3 学情分析页

验收项：

- 学情分析页仍保留现有整体 Tab：班级学情、个人学情、知识图谱、作业分析。
- 不在学情分析页内部新增校本教研 Tab。
- URL 中已有 `tab=profile/personal/kgraph/homework` 能正常回显。
- 切换 Tab 不丢失班级上下文。

不通过情况：

- 学情分析页 Tab 顺序和语义被大幅改乱。
- 切换到个人学情或知识图谱时报错。

## 3. 四维画像验收

### 3.1 维度完整性

班级画像和个人画像都必须展示四个维度：

- 知识点画像。
- 能力画像。
- 素养画像。
- 学习过程表现画像。

验收项：

- 班级学情页能看到四维画像总览。
- 个人学情页能看到同样四个维度。
- 四个维度命名、顺序、颜色和解释样式在班级/个人页面保持一致。
- 新增维度优先放在页面上方，至少在知识图谱与明细区域之前出现。

不通过情况：

- 班级有四维，个人只有两维。
- 个人有四维，班级没有。
- 维度名称在两个页面不一致。

### 3.2 雷达图展示

验收项：

- 新增画像维度默认使用雷达图展示。
- 雷达图在数据完整时正常绘制。
- 数据缺失时展示“暂无数据”或“证据不足”，不把缺失值强行画成 0。
- 雷达图在 1366px、1440px、1920px 宽度下不重叠、不溢出。
- 雷达图在窄屏下能换行或降级，不遮挡文字。

不通过情况：

- 图表空白但没有解释。
- 文案压到图表上。
- 因某个维度缺字段导致整个页面白屏。

### 3.3 班级和个人同构

验收项：

- 班级画像和个人画像复用同一套维度结构。
- 班级画像展示班级均值、分布、共性解释。
- 个人画像展示个人值、班均对比、个人解释。
- 个人画像可看到“低于/高于班均”的解释。

不通过情况：

- 班级和个人使用两套完全不同字段，导致维护困难。
- 个人页面没有班均对照。

## 4. 班级学情页验收

验收项：

- 班级学情页不再展示学生清单。
- 班级页可以展示待关注人数、分层摘要、共性问题，但不铺开学生列表。
- 查看学生明细统一进入“个人学情”Tab。
- 原学生清单移除后页面布局不留大面积空白。

不通过情况：

- 班级学情页仍展示完整学生列表。
- 删除学生清单后导致图表区域高度塌陷或空白异常。

## 5. 知识图谱与解释性验收

### 5.1 筛选项

知识图谱至少支持以下筛选：

- 时间窗：近 7 天、近 1 个月、近 3 个月。
- 数据来源：作业、考试、课堂互动、人机交互、自主练习。
- 维度类型：知识点、能力、素养、学习过程表现。
- 掌握状态：待巩固、练习中、较熟练、已掌握、证据不足。
- 证据强度：样本充足、样本偏少、久未更新。

验收项：

- 筛选项改变后图谱节点和解释语句同步变化。
- 无匹配数据时展示空态，不报错。
- 筛选项可清空或恢复默认。

不通过情况：

- 筛选后页面白屏。
- 图谱变了但解释仍显示旧口径。

### 5.2 解释语句

验收项：

- 低分知识点旁展示原因提示。
- 四维画像中的低分维度展示解释语句。
- 样本量不足时明确提示“证据不足”。
- 久未更新时提示“久未作答，读数可能滞后”。
- 每条建议至少展示 1 条证据摘要。

解释语句最低结构：

- 结论。
- 原因。
- 证据来源。
- 样本量或关键数据。
- 下一步建议。

示例验收文本：

- “该知识点掌握度偏低，主要因为最近一次单元测中关联题目正确率为 42%，显著低于班级近三次均值 68%。”
- “该学生在函数图像解释上证据不足，近 30 天仅有 2 条有效作答，不建议直接判断为薄弱。”

不通过情况：

- 只显示分数，没有说明为什么。
- 文案与当前筛选条件不一致。
- 样本不足仍给出强判断。

## 6. 校本教研验收

### 6.1 列表页

验收项：

- 校本教研一级页面有议题列表。
- 列表展示问题标题、教师、学科/年级、关联知识点或能力项、证据摘要、回复数、状态。
- 支持按学科、年级、知识点、状态筛选。
- 点击议题能查看详情。

不通过情况：

- 页面只有静态说明，没有可浏览议题。
- 列表缺少证据摘要，看不出议题从哪里来。

### 6.2 详情页或详情区域

验收项：

- 能看到问题描述、关联证据、教师回复、共识策略。
- 共识策略支持“引用到教案”的入口或占位按钮。
- 数据为空时展示空态。

不通过情况：

- 点击议题无响应。
- 详情只展示标题，没有交流和共识沉淀。

## 7. 兼容与稳定性验收

### 7.1 旧数据兼容

验收项：

- 老 mock 中没有素养画像、学习过程表现时，页面显示“暂无数据”。
- 老 mock 中没有 explanation 时，页面显示基础口径说明。
- 老 mock 中没有 evidence_strength 时，默认按“样本充足”或“未标注”展示，不报错。

不通过情况：

- 新字段缺失导致 `Cannot read properties of undefined`。
- 单个图表失败导致整页白屏。

### 7.2 已有链路回归

必须验证以下页面可打开：

- `/`
- `/learning-analysis`
- `/learning-analysis?tab=personal`
- `/learning-analysis?tab=kgraph`
- `/learning-analysis?tab=homework`
- `/design`
- `/paperCompose`
- `/setTopic`
- `/teach/correction`
- 新增校本教研路由

不通过情况：

- 任一路由 404。
- 任一路由白屏。
- 任一路由控制台出现阻断性运行时报错。

### 7.3 构建验收

验收项：

- `npm run build:demo` 成功。
- 不新增未声明依赖。
- 不引入会破坏生产构建的 mock-only import。

不通过情况：

- 构建失败。
- 构建通过但运行时报缺包。

## 8. 建议测试清单

### 8.1 手工冒烟

1. 登录演示账号。
2. 打开首页，确认原首页结构正常。
3. 打开学情分析，确认四个原 Tab 可切换。
4. 打开班级学情，确认四维画像展示，且没有学生清单。
5. 打开个人学情，确认四维画像展示，且有班均对照。
6. 打开知识图谱，切换时间窗、来源、维度类型、掌握状态。
7. 查看低分项解释语句。
8. 打开校本教研一级菜单，查看议题列表和详情。
9. 回到教学设计、作业组卷、作业下发、作业批改，确认可正常进入。

### 8.2 自动化冒烟建议

至少覆盖：

- 页面加载不白屏。
- 左侧菜单点击可达。
- 学情分析 Tab 切换可达。
- 四维画像容器存在。
- 图谱筛选后仍有空态或节点。
- 校本教研列表存在。

## 9. 最终交付标准

达到以下条件可认为本阶段通过：

- 新增校本教研一级菜单，不影响现有菜单。
- 学情分析页没有被重构成新产品结构。
- 班级/个人画像四维同构。
- 新增雷达图和解释性文案正常展示。
- 班级学情页无学生清单。
- 图谱筛选和解释增强可用。
- 校本教研列表和详情可用。
- 旧 mock 缺字段不白屏。
- `npm run build:demo` 通过。

## 10. 本次实现的补充验收

实施记录见 [开发验收记录](教师端画像与校本教研开发验收记录-2026-09-20.md)。

- 连续切换三个班级，最终显示最后选择班级的数据。
- 班级、个人、知识图谱共用 URL 时间与来源；刷新和 Tab 切换后口径一致。
- 画像采用固定日期快照时，页面明确显示快照时间。缩小范围后只筛选真实证据摘要；缺乏完整统计数据不能伪造分数。
- 未覆盖学生不借用他人或班级分数；缺失指标不能作为 0 分绘制。
- 雷达不仅容器存在，还要检查画布非空，并验证第一次调整窗口尺寸即可正确重绘。
- 教研发布校验必填项；同帧重复点击回复仅新增一条；刷新后内容保留。
- 保存失败时保留输入并提示失败，不显示“保存成功”。
- 教研策略带入教学设计后，实际生成请求包含策略、证据、来源，生成正文与历史详情保留这些内容。
- 新画像接口报错时，旧学情区域仍可查看，点击重试可恢复画像。
- 浏览器冒烟覆盖 1366、1440、1920 和 390 像素宽度。
- 时间预设按钮的文字边界必须落在按钮内，不能因窄屏换行超出固定高度；新增画像容器不得产生横向溢出。
- 画像缺少当前范围统计时，统一说明已覆盖时间；“查看已有快照”恢复真实快照日期和来源，个人与班级均适用。
- 画像指标名称、数值和班均刻度不相互遮挡；窄屏个人画像与班级画像均检查左右边界。
- 新观测数据交付前，不得把旧快照的分数用作任意新筛选条件下的分数。
