# 教师端画像与校本教研 Mock 数据清单

> 下一批补数请优先使用 [画像时间筛选补充 Mock 说明](画像时间筛选补充Mock说明-2026-09-20.md)。已确认缺少时间/来源可拆分观测、课堂/人机交互证据和 105 名学生的四维数据；新说明约定按观测记录统一计算，不再通过复制固定快照补数。

## 1. 使用范围

本清单用于补齐前端演示所需 mock 数据。目标是支撑以下页面：

- 班级学情
- 个人学情
- 知识图谱
- 作业分析中的解释性建议
- 新增左侧一级菜单“校本教研”

核心要求：

- 班级画像和个人画像字段同构。
- 四维画像都要有数据：知识点、能力、素养、学习过程表现。
- 所有关键读数要能给出解释语句。
- 图谱筛选项需要有足够字段支撑。
- 校本教研一级页面要能展示论坛式问题、回复和共识沉淀。

## 4. 四维画像建议指标

### 4.2 能力画像

建议 radar_items：

- 表征转换
- 运算推理

- 迁移应用

### 4.3 素养画像

- 学习态度
- 学习兴趣

### 4.4 学习过程表现画像

需要 mock：

- 时间窗枚举：近 7 天、近 1 个月、近 3 个月、自定义。
- 数据来源枚举：作业记录、考试记录、课堂互动、人机交互、自主练习。

## 9. 推荐 mock 文件拆分

建议按以下文件存放，便于前端消费：

- `teacher/data/profile-dimensions-class-<class_id>.json`：班级四维画像。
- `teacher/data/profile-dimensions-student-<class_id>.json`：该班学生四维画像集合。
- `teacher/data/profile-explanations-<class_id>.json`：班级和学生解释性提示。
- `teacher/data/knowledge-graph-filtered-<class_id>.json`：带筛选字段的知识图谱节点与边。
- `teacher/data/research-topics.json`：校本教研议题列表。
- `teacher/data/research-topic-detail-<topic_id>.json`：议题详情、回复和共识策略。

## 10. 最小可用 mock 规模

为了页面演示完整，建议最少准备：

- 3 个班级。
- 每班 8-12 个学生。
- 每个学生 4 个画像维度。
- 每个画像维度 5-6 个雷达指标。
- 每个班级 12-20 个知识图谱节点。
- 每个关键低分项至少 1 条 explanation。
- 每个 explanation 至少 1-3 条 evidence 摘要。
- 校本教研 8-10 条议题。
- 每条教研议题 3-5 条回复。
- 至少 3 条已形成共识策略，可展示“引用到教案”。

## 11. 接入情况与后续补数

2026-09-20 已接入 `mock/teacher/data/` 中的三班四维画像、解释、图谱及十条教研议题。源文件由 `scripts/prepare-demo-mock.js` 在构建时同步到浏览器目录；不要直接修改 `src/demo-mock/` 生成文件。

当前覆盖情况：

- 三个班级，每班十名学生有四维画像；个人学情保留全班原有名单，未覆盖学生显示暂无数据。
- 新画像是固定日期快照，不能从每条解释的 1-3 条摘要可靠推导任意时间窗的全量分数。
- 浏览器演示的发帖、回复、策略、引用状态使用 `teacher-research-demo-v1` 本地存储；这不是服务端多人共享数据库。
- 新增 `GET /api/teacher/portraits` 返回 `scope / snapshot / classSnapshot / graph / explanations / available_student_ids / coverage_note`。生产接入时可继续使用该结构。

为实现任意筛选范围下完整重算，下一批数据需要补充：

| 数据 | 必需字段或规则 | 用途 |
|---|---|---|
| 全班学生画像 | 所有已有 student_id 对应的四维维度；缺测项明确为 null | 避免只有十名学生有完整画像 |
| 不同时间窗快照 | start_date、end_date、sources、dimension_key、score、sample_count | 近7天/近1个月等筛选后真实更新画像 |
| 同口径班均 | 与个人快照完全一致的时间、来源、指标定义 | 个人与班级对照可复核 |
| 原始事件全集或聚合统计 | evidence_id、时间、来源、指标关联、统计分子/分母、去重规则 | 重算与解释数字一致 |
| 素养与过程观察 | 行为含义、观测次数、缺测、量表规则、适用时间段 | 不从作答正确率直接推断态度或价值观 |
| 样本覆盖说明 | 总人数、有效人数、去重人数、样本强度规则、最近有效时间 | 解释人数与事件条数，识别低样本和滞后 |

原快照字段保持兼容；建议新快照仍按现有命名与四维 key 组织，由接口选择相应时间与来源的快照。
