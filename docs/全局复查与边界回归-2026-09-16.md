# 全局复查与边界回归

日期：2026-09-16。项目：`edu_7net_fe-26_08_21`。

本次基于当前工作区（包含用户新改动）增量检查。重点检查路由与 URL 参数、请求和登录状态、学情切换、题库筛选、知识图谱、助手，以及教案历史／生成／预览链路。保留原有未提交修改。

## 确认并修复的问题

| 范围 | 触发条件及原有问题 | 本次处理 |
| --- | --- | --- |
| 助手发送 | 点击发送按钮时，事件对象被作为文本传入，调用 `.trim()` 报错；连续点击可能重复发送 | 分离事件与文本参数，用同步请求标记防重复 |
| 助手上下文 | 提问后切页面、班级或学生，旧回复／建议可能写入新会话 | 上下文变化取消请求并丢弃旧结果；异常后结束等待 |
| 个人学情深链接 | 带 `class_id`、`student_id` 进入，班级列表较慢时，旧班级默认学生可能覆盖 URL | 等待班级选择与 URL 一致后选学生；通过路由同步参数，支持刷新和返回 |
| 学情筛选 | 个人页修改日期没有重新取数；数据失败缺少明确反馈 | 日期／来源变化触发请求，个人画像／证据失败提供重试 |
| 空数据 | 班级列表为空仍保留旧班级，可能继续显示旧画像或骨架屏；空学生列表保留原学生 | 清空无效选择，显示空态，隐藏不匹配画像 |
| 题库竞态 | 筛选、目录树、翻页各有独立 hook，请求序号不能互相约束 | 模型统一请求序号，过期结果和离页结果不写回；失败显示重试 |
| 题库取消与刷新 | 旧请求结束会删除新请求的取消控制器；结果组件闭包过期，刷新时知识点／章节参数颠倒 | 控制器按身份清理；移除不完整依赖的回调缓存；修正参数顺序 |
| 资源知识图谱 | 快速切年级／节点后旧响应覆盖新状态；打开解释会重建图数据并重启布局 | 丢弃过期响应、取消旧解释；稳定图数据和事件引用，增加空节点／边保护 |
| 学情预览 | 快速切班级后，旧章节与新班级混用，迟到响应覆盖当前预览；异常可能无反馈 | 绑定章节所属班级，取消过期读取，清理超时和加载状态，展示错误 |
| 教材与班级注入 | 自动填充固定使用八年级教材 ID；预览班级变更没有带入生成表单，旧自动填充可能迟到覆盖新值 | 从接口目录匹配教材与 ID；匹配不到时要求手动选择；通过路由同步班级，丢弃过期自动填充，防止初始化覆盖已注入内容 |
| 教案预览评分 | 评分是数字时，部分组件调用字符串 `.includes()` 导致渲染异常 | 兼容数值／字母评分；预览支持显示 0；布置作业增加重复提交保护 |
| 引导弹窗 | 加载问题时关闭弹窗，迟到失败仍执行“直接生成”并导航 | 关闭／重新打开时使旧请求失效，完成和跳过防重复 |
| 教案生成收尾 | SSE end 帧 ID 尚未进入 React 状态，内容读取使用旧 ID；同 ID 内容更新不刷新 | 直接使用完成帧 ID，补齐内容同步依赖 |
| SSE 断流 | 连接提前结束、网络失败时缺少业务错误收尾，可能持续加载 | 检查完成帧，失败交给错误分支，停止思考／生成状态；忽略旧连接事件 |
| 登录与请求 | 登录失效标记永久锁住后续跳转；旧会话 401 可清除新登录；已有查询串拼接和百分号解码错误；PUT/PATCH 缺少 JSON 请求体 | 按请求所属身份处理失效；统一查询编码和请求体；常规读取设置超时，题库取消请求复用通用鉴权逻辑 |
| 页面异常恢复 | 某页错误边界进入降级后，导航到其他路由仍停留错误页 | 按 pathname 重建业务页错误边界；课时详情失败提供重试，详情请求／轮询增加离页守卫 |
| 演示教案链路 | 历史类型字段与页面判断不一致，课时进入单元；历史详情和生成后内容接口缺失；浏览器 Mock 缺少 SSE 使用的 `writeHead` | 规范历史类型并兼容旧标签；补齐详情和内容读取，保存有上限的演示会话内容；支持 SSE 响应头 |

最后一行属于本地演示环境修复，不代表真实后端已经通过同样验证。生成内容保存在演示会话内，刷新浏览器不会将它持久化到真实数据库。

## 验证结果

环境：`npm run build:demo` 构建、`http://127.0.0.1:4173` 静态预览、Chrome headless、1440×960。常规性能测量未做 CPU／网络节流；边界测试按场景主动注入失败、空数据、700–800 ms 延迟或截断响应。

- Demo 构建成功。
- `npm run test:performance` 通过：480 次 Mock 热响应，读取 JSON 共 8 次，p95 约 0.07 ms。此值仅包含函数处理和序列化。
- `node tests/boundary-regression.cjs` 通过：PUT/PATCH 请求体、特殊字符查询、新旧登录会话、重复失效跳转、路由参数保留、列表响应乱序／离页／失败、取消控制器归属。
- 常规浏览器回归通过：14 条页面／标签切换，48 次 API 请求，无页面 JavaScript 错误或未匹配的演示接口。
- 边界浏览器回归通过：14 项场景，无页面 JavaScript 错误。
- `git diff --check` 通过，仅存在工作区原有换行风格提示。

14 项浏览器边界场景：

1. 题库失败展示重试，重试后恢复。
2. 延迟班级列表时按指定班级／学生打开深链接，刷新和浏览器返回正确恢复。
3. 个人学情清空日期、切换来源重新取数。
4. 空学生列表不显示旧学生画像。
5. 无班级时显示空态，结束骨架加载。
6. 助手发送按钮、同一帧双击只发送一次。
7. 助手发送后离页，旧回复不进入新会话。
8. 快速切年级和稀疏层级图谱正常显示。
9. 连续点击节点，迟到解释不覆盖最后节点。
10. 学情预览快速切班，章节和内容保持当前班级。
11. 历史课时教案打开、数值评分显示、预览关闭、重复布置保护。
12. SSE 缺失完成帧时结束加载，可正常离页。
13. 引导加载期间关闭，迟到失败不导航；重新生成后使用有效 ID 读取内容并打开预览。
14. 替换接口返回的教材 ID 后，章节请求使用新 ID；模拟七年级且没有匹配教材时，表单留空并提示手动选择，不套用八年级章节。

## 剩余风险与验证范围

- 自动教材选择沿用当前功能默认的“下册”规则，匹配接口返回目录；没有匹配册别时需要教师手动选择。本地目录只有八年级，已验证其他年级缺失目录的回退，但其他年级完整内容仍需真实数据联调。
- 本次完整浏览器验证集中在学情、资源、助手和课时教案。单元教案完整生成、真实评估服务、文件上传／下载、大附件、导入、发布到课程、无界宿主登录与权限变化未完成端到端联调。
- 浏览器 Mock 的 SSE 响应被缓冲后返回；本次验证了完成和提前结束的处理，但不能代替真实长连接和长时间生成测试。
- 构建仍提示包体偏大。本机站内流转已验证，冷启动、弱网和低端设备仍需独立测量。
- 当前项目依赖中没有可执行的 TypeScript `tsc`，因此未完成全量独立类型检查；构建通过不能替代类型检查。

此次检查发现并修复了实际问题，但不能把通过这些回归用例等同于整个系统不存在其他缺陷。
