# 学情分析：分布列重叠与三图尺寸稳定性

## 原因与改动

- 分布列原宽度为 82px，但分布条设置了 110px 最小宽度。修复前在 1440px 窗口、助手侧栏模式下，实测单元格宽约 83px，条形向右跨进了掌握度列。现在分布列保留 128px，条形宽度限定在单元格内容区内。
- 表格的横向滚动宽度原为 560px，小于各列声明宽度之和。现在使用固定表格布局，滚动宽度从列宽求和；掌握度、人数、趋势列也留出完整内容所需空间。容器较窄时横向滚动，区间条和百分比各自在本列内排列。
- 三个图表原本被 `height: 100%`、卡片 `flex: 1` 和图表子元素 `flex: 1; min-height: 0` 同时约束。切到侧栏、分析行折行后，图表高度受父级拉伸影响。修复前实测三图高度约 131 / 103 / 131px，明显小于其原定高度 212 / 228 / 204px。
- 分析区改用 Grid。按扣除助手后的业务容器宽度，在左右两栏和上下排列间切换；第一阶段用独立高度稳定图表，后续对齐调整见下文。图例支持折行。
- 图表配置使用 `useMemo`，只在对应数据变化时更新，防止打开明细弹窗等无关状态变化再次提交配置、重播动画。保留数据变化时的正常动画与容器宽度适配。

## 验证方式

专项浏览器脚本：`tests/analysis-charts-browser.cjs`。

检查真实表格各行的分布条、区间条、百分比是否位于所属单元格内容区内，同时检查横向滚动后的边界。对三个图表和卡片逐帧采样，结合 ResizeObserver、画布尺寸/节点变化记录与 canvas 清空重绘计数，检查动画结束后是否仍持续改变尺寸或闪烁。初次侧栏场景连续观察 5 秒，其余观察窗口至少 2.2 秒。

覆盖 1024 / 1280 / 1440 / 1600 / 1920px 侧栏宽度、三轮浮窗与侧栏切换、图谱与表格切换、班级/来源/日期筛选、明细弹窗，以及长知识点名称、0%/100%、百人人数、空数据。模式切换额外检查原画布保持且没有新增数据请求。

浏览器截图及逐场景尺寸记录位于 `.temp/analysis-charts/`。已人工检查 1440px 下的分布表和三图、1024px 下三图的截图。

- `node tests/layout-browser.cjs`：10 个场景通过，包含资源图谱首次进入、侧栏切换与窄屏、教案布局和请求失败重试。
- `node tests/assistant-presentation-browser.cjs`：14 个场景通过，聊天、问候、位置切换、输入保留和虚化交互正常。
- `node tests/performance-browser.cjs`：14 次页面流转、48 次接口请求通过，无页面异常或未匹配演示接口。
- `node tests/performance-regression.cjs`、`node tests/assistant-presentation-regression.cjs`：缓存、请求隔离与 11 项助手页面上下文逻辑回归通过。
- 全量 TypeScript 检查仍有 671 项既有诊断。与前次记录按忽略行号后比较，没有新增诊断；并非全库类型检查通过。

以上是本机 Chrome 与演示数据的验证结果。保留测试脚本与逐段测量记录，后续可复测不同窗口尺寸及数据。

## 后续视觉对齐优化

针对分布卡底部空缺、三张子图高低不齐，统一了卡片结构和布局：

- 宽屏时，分布卡与右侧三图作为一组上下对齐。表格内容区随可用空间排布，减少表格结束后的空白，同时保留原来的最大滚动高度。
- 移除该表格在 Grid 内不再需要的 clearfix 伪元素，避免它们成为额外网格行。宽屏空数据测试曾测得表格底部多出约 166px 留白，修复后由实际表格占满内容区。
- 三张子图共用标题栏和绘图区结构，卡片按 Grid 等高排列。“查看人机交互明细”移到来源图标题栏，以“查看明细”按钮展示，悬浮提示和无障碍名称保留完整含义。
- 画布绝对定位在独立绘图区中，不参与父级固有高度计算；绘图区保留最小高度，避免之前画布与父容器互相影响而反复缩放的问题。
- 图表区域能放三列时并排等高，两列时排行图铺满第二行，一列时依次排列。使用图表区域自身的容器查询，兼容助手占位后的实际宽度。

专项脚本新增等高、左右两栏上下对齐、表格底部留白、两列时第三张图铺满第二行的断言。窗口覆盖增加到 1024 / 1280 / 1440 / 1600 / 1800 / 1920 / 2240px，并检查宽屏浮窗及宽屏空数据。

本轮验收：最终演示构建通过；14 项专项场景和 10 项已有布局场景通过。专项测试 24 段观测累计采样 13368 帧，没有持续尺寸变化、画布重建或清空重绘。实测三图横排和两行排列时卡片均为 286px 高；宽屏浮窗和宽屏空数据下三张卡均为 246px 高，左右两栏底部误差为 0px，表格底部保留正常的 15px 内边距。

已核对三图横排、两列布局及宽屏两栏的截图；结果记录位于 `.temp/analysis-charts/results.json`，本轮构建和回归日志为 `.temp/analysis-alignment-*.log`。
