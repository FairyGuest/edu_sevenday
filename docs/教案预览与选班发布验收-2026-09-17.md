# 教案预览、选班发布与班级问候

## 完成的调整

- 课时、单元教案共用分栏尺寸逻辑，横排和竖排分别保存比例。将分栏方向与实际容器尺寸同步更新，修复窄屏返回宽屏后右侧大量空白的问题；拖拽、折叠和助手侧栏切换仍可使用。
- 预览弹层使用可用窗口宽度，收紧正文间距。窄屏下工具栏换行、目录移到正文上方，保留全屏及关闭入口。
- 预览中的「布置作业」先打开选班弹窗，点击「确认发布」才提交。教案关联的学情班级有效时自动预选，也可改选；无关联时由教师选择，不使用其他页面的当前班级作为默认值。
- 班级列表支持加载、失败重试、空列表刷新及关联班级失效提示。发布失败保留选择，提交中防止重复点击；取消不发布，按 Escape 只关闭选班弹窗。
- 演示接口保存新生成课时及单元教案的班级、类型和历史记录，并拒绝不存在的发布班级。
- 班级学情及班级知识图谱的固定首个快捷入口为「注入班级学情到教学设计」。入口携带当前班级，不依赖画像建议接口是否成功。
