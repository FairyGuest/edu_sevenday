# 教师端画像与校本教研开发验收记录

## 实现范围

按本目录功能拆分文档的 P0/P1 实施，保留首页和学情分析四个 Tab，校本教研为左侧一级菜单。

| 功能 | 实现内容 |
|---|---|
| 首页与导航 | 恢复原首页四个模块；校本教研独立路由及刷新 |
| 四维画像 | 班级与个人复用四张雷达、指标列表、解释与证据展示 |
| 班级学情 | 移除学生清单，保留聚合统计与个人学情入口 |
| 个人学情 | 原名单与搜索保留，新增个人/班均对照，未采集学生空态 |
| 筛选与图谱 | 时间、来源共享；维度关联、掌握状态、证据强度、目标筛选；节点证据及相关教研 |
| 校本教研 | 问题列表、筛选、详情、回复、发帖、共识策略、引用证据 |
| 教案引用 | 带入班级、策略内容、实践依据、来源议题；生成正文及历史详情可查看 |
| 稳定性 | 读请求过期响应隔离、空数据兜底、错误重试、图表局部异常边界、写请求防重复 |

## 数据与联调边界

- 本轮为可运行的前端演示，新增接口由 Mock 实现，未接入真实教研数据库。
- 四维画像仅有固定日期快照和部分证据摘要，筛选后缺乏完整数据时明确不重算分数。
- 当前每班十名学生有新画像，其他学生仍能查看原有作答明细，新画像展示暂无数据。
- 校本教研新内容在同一浏览器刷新后保留；跨设备同步需要真实接口。
- P2 的人工修正留痕与统计版本管理不在本轮实现范围。
